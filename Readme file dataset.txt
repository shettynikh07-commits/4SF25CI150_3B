# Spotify Data Analysis Using Python

## Overview

This project focuses on analyzing Spotify music tracks using Python and Pandas. The dataset is explored, cleaned and transformed to generate meaningful insights about music popularity, energy, danceability and track duration.

## Objectives

* Read and understand a CSV dataset.
* Perform data transformation using Pandas.
* Identify and handle null values using mean imputation.
* Generate meaningful insights.
* Visualize the findings using graphs and charts.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

Spotify Tracks Dataset downloaded from Kaggle.

## Analysis Performed

* Dataset exploration
* Duplicate removal
* Data type conversion
* Null value handling
* Creation of new columns
* Statistical analysis
* Data visualization

## Conclusion

The project helps understand how Python can be used to clean, transform, analyze and visualize real-world music data.
